Grid Browse Wireframe

A clickable low-fi prototype of the grid overlay on the browse map. Every control works on sample data from towns around Szentendre.

Jump to

Try it

  • Drag the map sideways to move to the next town. The grid follows (Pomáz is empty).
  • Type "bud" in the grid's location field.
  • Remove a tag, or switch a type chip on the grid or on the map's layer buttons.
  • Scroll the grid: the fields fold into the summary, and more cards load.
  • Use the pin button on a card, and the ← in the address bar.

Decisions

  • The grid mirrors the map area. The header names it ("Szentendre & around"); picking a place fits the map to that place.
  • Mobile: full-screen overlay. Desktop: grid panel on the right, live map in the middle, detail drawer on the left.
  • One mixed grid. The type chips are the same setting as the map layers.
  • "⊞ N nearby" chip is always on the map: "…" while loading, "List view" at zero.
  • The grid has its own route, with tags and area in the query string. Back closes the drawer first, then the grid.
  • Cards are the existing map popup cards in a fluid 4:5 layout, 2 per row, nearest first, each with a pin button.
  • Fields fold into the pinned summary when scrolling; ⌄ reopens them.
  • Infinite scroll with skeleton cards (pages of 24 planned; 8 then 6 here).
  • Empty area: a short message and the invite button.
  • Desktop: hovering a card highlights its pin; the pin button pans the map without reloading; any other pan reloads the grid 400 ms after the map stops.
